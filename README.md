# Presentations

This repo collects the slides of the INCOSE **Sustainability Webinar Series (SWS)** and
the presentations that the Sustainability Virtual Lab and the INCOSE Sustainability
Working Group gave.

> **Rights.** The speakers agreed to publish their slides here. They keep the
> copyright, and this repo has no open license. You can read and link the decks.
> To reuse slides or content in your own material, ask the speaker first. The
> "Rights" column shows what the deck itself says.

## Add a deck

1. Get the speaker's permission to store the deck here.
2. Name the file `YYYY-MM-DD_<type>-<nr>_<Speaker>_<Short-Title>.pdf`, for example
   `2025-10-29_SWS-04_Baue_Hacking-Sustainability-Standards.pdf`.
3. Add a row to the table above, with the rights statement from the deck.
4. Open a pull request.
